# Token Prediction using Self-Attention (Character-Level Language Model)

An end-to-end character-level language model built from scratch in PyTorch using a custom-implemented Transformer architecture. This model is trained on the classic **Tiny Shakespeare** dataset to predict the next token (character) in a sequence, learning to generate stylistically coherent Shakespearean text.

## 🚀 Project Overview
This project demonstrates the core mechanics behind modern Large Language Models (LLMs). Instead of using pre-built layers like `nn.TransformerEncoder`, this repository implements self-attention, multi-head attention, feed-forward networks, and transformer blocks entirely from scratch using PyTorch primitives.

## 🛠️ Implementation Approach

### 1. Data Pipeline
* **Dataset:** Tiny Shakespeare dataset (~1.1M characters).
* **Tokenizer:** Character-level tokenization (vocabulary size of 65 unique characters mapped to unique integers).
* **Data Splitting:** 90% training data, 10% validation data.
* **Batching:** Randomly sampled sequences of length `block_size = 256` grouped in batches of `batch_size = 64`.

### 2. Model Architecture
Our `TransformerLanguageModel` consists of:
* **Token & Position Embeddings:** Map input characters and their relative spatial positions into a high-dimensional continuous space (`n_embd = 384`).
* **Transformer Blocks (x6):** Sequential communication and computation blocks consisting of:
  * **Multi-Head Attention:** 6 attention heads operating in parallel, using causal masking (`tril`) to prevent future tokens from influencing current predictions.
  * **Layer Normalization:** Applied before the communication and feed-forward operations (pre-LN formulation) for stable gradient flow.
  * **Feed-Forward Network:** A simple multi-layer perceptron with a ReLU activation and dropout to project and process representations.
* **Final Layer Norm & Linear Head:** Projects final transformer outputs to the vocabulary space to yield logit predictions.

### 3. Hyperparameters
* **Embedding Dimension (`n_embd`):** 384
* **Attention Heads (`n_head`):** 6
* **Transformer Layers (`n_layer`):** 6
* **Block/Context Size (`block_size`):** 256 characters
* **Batch Size (`batch_size`):** 64
* **Optimizer:** AdamW (Learning Rate: `3e-4`)
* **Dropout Rate:** 0.2

## 📊 Training Results

The model was trained for **5,000 iterations** using a cross-entropy loss objective:

* **Initial State (Step 0):** 
  * Train Loss: `4.1821` | Val Loss: `4.1829`
* **Middle State (Step 2500):**
  * Train Loss: `1.1348` | Val Loss: `1.4893`
* **Final State (Step 4999):**
  * Train Loss: **`0.8637`** | Val Loss: **`1.5641`**

### Loss Curve Observation
The model achieves excellent representation capability, driving training loss below `0.9`. The discrepancy between training and validation loss (`1.56`) points to standard overfitting, typical of character-level models with relatively high capacity trained on compact datasets.
